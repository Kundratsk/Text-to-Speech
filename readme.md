
# Text-to-Speech

## About the Project

I created this project to put the theoretical knowledge I learn at school into practice.

Instead of only reading about different technologies in theory, I wanted to build something practical and learn by experimenting.

The goal of this project is to explore how Text-to-Speech (TTS) technology works and how written text can be converted into spoken audio.

## Project Goals

- Apply theoretical knowledge in practice.
- Learn how Text-to-Speech technology works.
- Improve my programming skills.
- Gain experience with building a practical project.
- Learn through experimenting and problem-solving.

## Technologies Used

- JavaScript
- Node.js
- npm

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Kundratsk/Text-to-Speech.git
```

### Navigate to the project folder

```bash
cd Text-to-Speech
```

### Install dependencies

```bash
npm install
```
